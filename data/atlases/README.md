# Atlas resources

The CHN weekly cortical surfaces and CRL cortical labels are external resources
and are not redistributed in this repository.

Before running the spatial permutation scripts, download the atlas resources from
their official repositories and place them under the following local directories:

```text
data/atlases/chn_weekly_surface/
data/atlases/crl_weekly_labels/
```

Add the final source URLs, citations, and license statements here before release.
